# Joyería Gilbert 💎

Sitio web desarrollado para **Joyería Gilbert**, una marca dedicada a la venta de joyas elegantes y modernas.  
El proyecto busca transmitir confianza, estilo y exclusividad a través de un diseño minimalista y responsivo.

---

## 🚀 Características

- **Diseño responsivo**: Adaptado para móviles, tablets y escritorio.
- **Interfaz moderna**: Uso de tipografía elegante y colores sobrios.
- **Galería de productos**: Presentación clara y atractiva de las joyas.
- **Contacto directo**: Sección para comunicación rápida con la marca.
- **Optimización SEO básica**: Títulos y descripciones pensados para buscadores.

---

## 🛠️ Tecnologías utilizadas

- **HTML5** – estructura semántica del sitio.  
- **CSS3** – estilos personalizados y diseño responsivo.  
- **JavaScript** – interactividad y dinamismo.  
- **GitHub Pages** – despliegue del proyecto.
